# Security policy

## Supported versions

Security fixes are currently considered for the `1.0.x` release line.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/HetongLin/mneme/security/advisories/new), when available for this repository. Include enough detail to reproduce the issue, its potential impact, and any suggested mitigation.

Do not open a public issue for a security vulnerability, and do not include API keys, tokens, private notes, or other sensitive data in a report. For non-sensitive bugs, use the repository's public bug report form.

The maintainers will assess reports and coordinate any fix or disclosure through GitHub. No response-time or resolution-time guarantee is provided.
