# Stable identity

A stable identity remains unchanged when a note title or file location changes. Keeping identity separate from presentation preserves links and review history.

For example, a learning card can keep the same ID when its question is reworded or its Markdown file is moved. Scheduling and past reviews still belong to that same card.

A title is a useful label, and a path tells you where to find a file. Neither should determine whether it is the same learning object.
