# Stable IDs are the only identity for durable state

Mneme keys durable Concept and Card state only by immutable Concept IDs and Card IDs. Markdown paths, folder names, titles, and Card indexes are mutable locators or presentation details and must not become long-term identity. New Mneme assets always include explicit stable IDs; legacy assets with missing or duplicate IDs remain readable but enter a Repair Flow before Mneme creates new durable review or relationship state for them.
